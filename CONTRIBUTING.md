# Contributing

This is a personal tool, not an open project.

I am not looking for pull requests, issues, or feature requests. If you forked
it, you are on your own — including every hardcoded path and machine-specific
default.

How I run it is in [docs/GETTING_STARTED.md](docs/GETTING_STARTED.md) and
[docs/USAGE.md](docs/USAGE.md). That is documentation for this machine, not an
invitation to contribute.

Do not open PRs that “make it work on any machine.” That is future work I may
do; it is not a contribution invitation.
